# Quantitative and Digital Skills Portfolio – Nurbek Akhmetiyar

## Project 1: Portfolio and Investment Analysis
This project demonstrates financial data analysis using historical weekly returns for **Apple (AAPL)** and **Walmart (WMT)** for the year 2024.

### Key Skills Demonstrated:
* **Quantitative Analysis:** Calculated expected returns, standard deviation (risk), and correlation.
* **Digital Tools:** Automated data retrieval using `GOOGLEFINANCE` API and processed data in Excel.
* **Investment Strategy:** Evaluated diversification benefits; achieved risk reduction in a 50/50 portfolio.

### Statistical Summary:
* **Correlation Coefficient:** 0.24 (Weak positive correlation, providing good diversification).
* **Weekly Returns:** AAPL (0.72%) | WMT (1.13%).
* **Risk (Volatility):** AAPL (3.01%) | WMT (2.29%).
